## Alcance

Tener un comando único reproducible para ejecutar el pipeline completo y facilitar su operación desde README.

## RF10-01 completado

Se implementó el CLI principal:

- `erp-fraud run`
- módulo: `src/erp_fraud/cli/main.py`

Flujo encadenado actual:

1. Ingesta desde zip (`joint_datasets`)
2. Normalización de tipos y limpieza técnica
3. Carga en DuckDB
4. `schema_summary.json` + `run_metadata.json`
5. Validación técnica previa (`data_validation_report.json`)
6. Ejecución de tests de catálogo (`test_runs.json`, outputs por test)
7. Agregación/ranking (`ranking.json`/`ranking.parquet`)
8. Reporte (`report.json`, `report.md`, `report.html`)
9. Validación de links de artefactos en el reporte

Comando base:

```bash
python3 -m src.erp_fraud.cli.main run --input-zip erp_fraud_data.zip
```
