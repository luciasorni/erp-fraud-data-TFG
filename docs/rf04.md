# RF04 - Estado

## Alcance

Motor de ejecución seguro para tests de catálogo, con allowlist, tiempos por test/fase, captura de errores y continuidad del run.

## Entregado

- `TestRunner` con:
  - `run(test_spec)`
  - `run_all(selected_tests)`
  - `run_all_from_catalog(...)`
- Lista blanca de ejecución:
  - solo se permiten `test_id` existentes en `tests/catalog`
  - IDs fuera de catálogo -> error controlado
- Medición de tiempos:
  - por test (`duration_ms`, `runner_duration_ms`)
  - por fase (`selection`, `execution`, `total`) en `last_run_metrics`
- Manejo de errores por test:
  - excepción -> `status=ERROR`, `error_summary`
  - el runner continúa con el resto de tests
- Timeouts por test (best-effort):
  - `timeout_ms` opcional
  - si excede -> `status=TIMEOUT` y continuar
- Persistencia:
  - `test_runs.json` con campos mínimos por test:
    - `test_id`, `version`, `status`, `duration_ms`, `error_summary`
- Logging por test:
  - `test_start` / `test_end` en JSONL
  - contexto `run_id`, `test_id`, `status`, `duration_ms`

## Artefactos

- `run_results/<run_id>/test_runs.json`
- `run_results/<run_id>/test_runner_logs.jsonl`
