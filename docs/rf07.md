# RF07 - Estado

## Alcance

Agregar hallazgos de múltiples tests y producir un ranking de sospechosos con scoring configurable por pesos.

## RF07-01 completado

Se definió el formato base de configuración de pesos en:

- `config/weights.yaml`

### Estructura definida

- `schema_version`: versión del contrato del fichero.
- `defaults.severity_weights`: pesos base por severidad (`low|medium|high|critical`).
- `defaults.fallback_weight`: peso por defecto si no hay severidad válida.
- `overrides.by_test_id.<TEST_ID>.weight`: peso específico por test.
- `overrides.by_test_id.<TEST_ID>.reason`: justificación documental del override.

### Regla de prioridad (documentada para RF07-02)

1. Si existe `overrides.by_test_id[test_id].weight`, se usa ese valor.
2. Si no, se usa `defaults.severity_weights[severity]`.
3. Si tampoco existe severidad válida, se usa `defaults.fallback_weight`.

## RF07-02 completado

Se implementó cálculo base de scoring:

- Módulo: `src/erp_fraud/catalog/scoring.py`
- Fórmula: `score_test = weight * metric_value`

### Reglas de cálculo

1. `weight` se resuelve por prioridad:
   - `overrides.by_test_id[test_id].weight`
   - `defaults.severity_weights[severity]`
   - `defaults.fallback_weight`
2. `metric_value` se extrae de `metrics` del hallazgo:
   - `duplicate_count`
   - `z_score` (valor absoluto)
   - `amount_score`
   - fallback `1.0`
3. `score_test` es el producto de ambos.

Funciones disponibles:

- `load_weights_config(path)`
- `resolve_test_weight(...)`
- `extract_metric_value(metrics)`
- `compute_score_test(...)`
